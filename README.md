# Politique de confidentialité Android

`index.html` est la page autonome destinée à GitHub Pages : français puis anglais,
ancres, CSS embarqué, aucun script, police, image ou chargement externe automatique.
Les liens externes sont de simples liens de navigation.

Éditeur : Younes Tsouli, particulier. Contact : younesdbusinessman@gmail.com.
Le fichier source précédemment nommé `istighfar-privacy.html` a été replacé au
chemin `index.html` demandé pour éviter deux politiques contradictoires.

À décider avant mise en ligne : date réelle à remplacer aux deux emplacements
`[DATE DE PUBLICATION]` / `[PUBLICATION DATE]` ; URL publique GitHub Pages à confirmer
et à renseigner dans EXPO_PUBLIC_PRIVACY_URL ainsi que dans Play Console.
Aucune publication ou modification de configuration de l’application n’est effectuée.
